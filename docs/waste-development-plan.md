# Направление вывоза в MSK TEXBot

База разработки — `feature/main-menu-navigation` на `98255da`. Категория «Самосвал» сохраняется как заявка на технику. Сценарий вывоза описывает требуемую услугу и использует действующую модерацию и систему откликов.

## Схема данных

| Таблица | Состояние | Поля и связи |
|---|---|---|
| `leads` | Используется | Общий ID, заказчик, контакт, адрес погрузки, дата, условия и статус. |
| `lead_routing` | Используется | Один набор географии на заявку. Категория вывоза, регион и район погрузки. |
| `lead_payment_preferences` | Используется | Форма оплаты из анкеты по ID заявки. Отсутствующая запись отображается как «Не указана». |
| `waste_lead_details` | Добавлена в первом PR | Один набор параметров по ID заявки. Направление, материал, заявленный класс при наличии, услуга, объём в литрах, опциональная масса в кг, условия погрузки, адрес приёма при наличии. |
| `waste_provider_profiles`, `waste_provider_fleet`, `waste_provider_materials`, `waste_provider_areas` | План | Расширения существующего профиля. Специализации и услуги, типы и количество транспорта, кузов, грузоподъёмность, погрузочная техника, материалы и география. |
| `waste_provider_document_checks` | План | Провайдер, тип документа, номер или реестровая ссылка, разрешённые операции и материалы, срок, решение модератора, источник и дата проверки. |
| `acceptance_sites`, `acceptance_site_revisions`, `acceptance_site_materials` | План | Площадка, владелец, версии карточки, регион, адрес, координаты, время работы, условия, цена, контакты, материалы и решения модерации. |

Общая заявка, география, оплата и параметры вывоза записываются одной транзакцией. Для обычных заявок строка в таблице вывоза отсутствует. Значения класса заявляет пользователь, а подтверждённый статус относится к отдельной проверке документов. В карточке для канала выводится район погрузки. Телефон и отдельные поля точных адресов остаются в карточке модератора.

## Последовательность небольших PR

1. **Анкета заказчика.** Грунт, стройотходы и снег, три вида услуги, параметры перевозки и ручная модерация. Исправление текста «груз, навесное оборудование». Приёмка проверяет обычный «Самосвал», сохранение оплаты PR №8, возврат по шагам и единственную публикацию при повторе.
2. **Профили перевозчиков.** Расширить регистрацию для вывоза. Учитывать услуги, материалы, регионы и параметры парка. Проверить сохранность прежних профилей, техники и способов оплаты на копии с тестовыми данными.
3. **Документы и подбор.** Добавить закрытую очередь проверок и историю решений. Подбирать по направлению, географии, услуге, парку, материалу и применимой проверке документов. Для отходов I–IV классов при транспортировании проверять лицензию и область её действия. Неизвестный класс отправлять на уточнение. Приёмка выполняется в тестах и закрытом боте без адресной отправки.
4. **Каталог площадок.** Добавление администратором или владельцем, очередь модерации и просмотр одобренных версий. Проверять права на редактирование и скрытие приостановленных карточек. Карточка указывает, какие сведения проверены и когда.
5. **Связь заявки с площадкой.** Предлагать подходящие одобренные карточки по региону, материалу и условиям. Сохранить возможность указать адрес вручную. Карта, расстояние и геокодирование идут следующим отдельным PR после согласования источника координат.

Каждый PR проходит GitHub Actions, проверку совместимости и ручной сценарий в тестовом Telegram-боте. Выпуск рабочего бота согласовывается отдельно.
