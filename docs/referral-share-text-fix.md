## Причина и границы исправления

`urlencode()` по умолчанию использует `quote_plus`: пробел становится `+`.
В проверенном владельцем iPhone-пути эти знаки остались в тексте.
Прежний тест с `parse_qs` скрывал несовместимость: этот декодер сам
заменяет `+` пробелом. Новая проверка декодирует только percent escapes,
воспроизводя наблюдавшееся поведение; она падает до исправления.

Оба стандартных share/url перехода используют один helper с
`urlencode(..., quote_via=quote)`: пробел `%20`, перенос `%0A`, настоящий
плюс `%2B`. Добавлены абзацы и инструкция открыть бота по ссылке и нажать
«Запустить». Персональная ссылка, выбор получателя и подтверждение отправки
в Telegram сохраняются. Inline-карточка использует тот же читаемый текст;
включать inline через BotFather для стандартного пути не требуется.
Никаких изменений схемы, учёта, /start, lead_, contact_, транспортных прав
или настроек Worker.
